# Grammalecte Android 1.0.0 — Draft release notes

> DRAFT — Not published. Review before creating the stable tag.

## Français

Première version stable prévue de Grammalecte Android, correcteur
orthographique et grammatical français libre, fonctionnant hors ligne.

### Fonctionnalités

- Correction native via SpellCheckerService, dans les applications compatibles.
- Correction du texte sélectionné via ACTION_PROCESS_TEXT.
- Clavier Grammalecte (IME) pour corriger une sélection dans un champ éditable.
- Dictionnaires français, règles configurables et dictionnaire personnel.
- Aucune permission Android INTERNET.

### Compatibilité

Android 8.0 ou supérieur (API 26+).

Tests automatisés validés sur API 26, 35 et 37.
Tests physiques réalisés notamment sur Samsung Galaxy S21 / Android 15.

La compatibilité dépend des applications et des versions d'Android.

### Limitations connues

- GrapheneOS Android 17 : échec du correcteur natif signalé sur un
  Pixel 9 avec la RC1. Investigation en cours : issue #34.
  Cela ne démontre pas une incompatibilité générale avec Android 17.
- Samsung Messages : PROCESS_TEXT peut insérer la correction après
  le texte sélectionné au lieu de le remplacer (issue #50).
  Le mode IME fonctionne dans la configuration Samsung testée.
- Certaines applications ignorent les mécanismes natifs de correction
  ou les résultats de remplacement PROCESS_TEXT.

### Distribution

Version prévue : 1.0.0 (versionCode 3).
Moteur embarqué : Grammalecte 2.3.0.

La signature Android devra être identique à celle de la RC1.
La publication sur F-Droid reste soumise à l'acceptation de !54224.

## English

Planned first stable release of Grammalecte Android, a free,
fully offline French spelling and grammar checker.

### Features

- Native SpellCheckerService integration in compatible Android editors.
- Selected-text correction through ACTION_PROCESS_TEXT.
- Grammalecte IME for correcting selections in editable fields.
- French dictionaries, configurable rules and personal dictionary.
- No Android INTERNET permission.

### Compatibility

Android 8.0 or later (API 26+).

Automated instrumentation passed on API 26, 35 and 37.
Physical-device validation includes Samsung Galaxy S21 / Android 15.

Compatibility depends on the Android version and host application.

### Known limitations

- GrapheneOS Android 17: native spell-checker session failure reported
  on a physical Pixel 9 with RC1 (issue #34). Investigation is ongoing.
  This does not establish incompatibility with Android 17 generally.
- Samsung Messages: PROCESS_TEXT may append corrections instead of
  replacing selected text (issue #50). IME replacement works in the
  tested Samsung configuration.
- Some Android editors do not support native spell checking or
  PROCESS_TEXT replacement.

### Distribution

Planned version: 1.0.0 (versionCode 3).
Embedded engine: Grammalecte 2.3.0.

The Android release signing certificate must remain unchanged.
Official F-Droid inclusion is pending upstream MR !54224.
